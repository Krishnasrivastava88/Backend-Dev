## How to Run a Specific Branch

1. Clone the repository:

```
git clone https://github.com/Krishnasrivastava88/Backend-Dev.git
```

2. Move into the project folder:

```
cd Backend-Dev
```

3. Switch to a branch:

```
git checkout branch-name
```

Example:

```
git checkout express-framework
```

4. Install dependencies (if package.json exists):

```
npm install
```

5. Run the server:

```
node server.js
```

or

```
npm start
```
